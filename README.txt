CARNÍVORA 40+ — UPSELL ESTÁTICO

Arquivos:
- index.html = upsell
- downsell.html = downsell
- styles.css = visual
- app.js = links dos botões

PUBLICAÇÃO
1. Suba todos os arquivos para o GitHub ou direto na Vercel/Netlify.
2. Não precisa de npm, framework ou build.
3. A página inicial é index.html.

CONFIGURAÇÃO
Abra app.js e troque:
- COLE_AQUI_O_LINK_DO_UPSELL
- COLE_AQUI_O_LINK_DO_DOWNSELL
- COLE_AQUI_O_LINK_DA_AREA_DE_MEMBROS

Preços usados no exemplo:
- Upsell: R$ 47,90
- Downsell: R$ 19,90

OBSERVAÇÃO
O verdadeiro upsell de 1 clique depende da plataforma de checkout. Se ela fornecer um link/endpoint específico para adicionar a oferta à compra anterior, coloque esse link no app.js. Caso contrário, use um checkout separado.

O mockup do produto é feito em CSS, então não há arquivo de imagem obrigatório.
